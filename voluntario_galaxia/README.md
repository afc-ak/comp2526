# Voluntario Galaxia

Proyecto del voluntario `voluntario_galaxia` que simula el movimiento de galaxias y estrellas.

## Archivos principales

- `galaxia.py` - Código principal de la simulación.
- `galaxias_lichu.py` - Simulación adicional o variación de galaxias.
- `gif_galaxias.py` - Script para generar animaciones de galaxias.
- `grafica_galaxias.py` - Script para graficar resultados de la simulación.
- `Voluntario_ATAULFO-FERNANDEZ-CRUJEIRAS_galaxia.pdf` - Informe en PDF del proyecto.

## Datos

- `estrellas_lichu.txt` - Posiciones de estrellas usadas en la simulación.
- `estrellas_posiciones.txt` - Datos de posición de las estrellas.
- `periodo.txt` - Información relacionada con el período de movimiento.

## Imágenes / animaciones

- `galaxy_movement.gif` - Animación del movimiento de galaxias.
- `lichu_movement.gif` - Animación de movimiento de los datos de `lichu`.

## Uso

1. Abrir el PDF para leer la descripción del proyecto:
   - [Informe del proyecto](Voluntario_ATAULFO-FERNANDEZ-CRUJEIRAS_galaxia.pdf)

2. Ejecutar el script principal:

```bash
python galaxia.py
```

3. Si quieres generar o revisar animaciones, usa:

```bash
python gif_galaxias.py
python grafica_galaxias.py
```
